# Color System

Grover uses natural materials as inspiration without turning the interface into a
literal landscaping theme. Evergreen carries brand and primary-action weight;
bone and paper keep large surfaces warm; clay, gold, sky, and sage communicate
state with restrained contrast.

## Core palette

| Token | Value | Primary use |
| --- | --- | --- |
| Evergreen | `#173F35` | Brand fields, navigation, primary actions |
| Forest | `#0F2F28` | Deep navigation and high-contrast surfaces |
| Evergreen 2 | `#24594A` | Progress, positive state, hover emphasis |
| Bone | `#F6F2E8` | Application and marketing canvas |
| Paper | `#FFFDF8` | Cards, drawers, forms, data surfaces |
| Ink | `#17342D` | Primary text |
| Slate | `#5D6E67` | Secondary text and metadata |
| Line | `#D8DDD7` | Dividers, borders, inactive controls |
| Sage | `#8EA795` | Supporting brand color |
| Sage soft | `#DCE6DE` | Neutral-positive badges and selected fields |
| Sand | `#DEC79D` | Premium warmth on dark fields |
| Gold | `#C99F55` | Attention without failure semantics |
| Clay | `#BD6848` | Risk, destructive action, blocked work |
| Sky | `#DCE8EB` | Informational and scheduling context |

## Semantic rules

- Color reinforces status; it never carries status alone.
- Evergreen means progress, persisted success, active navigation, or the primary
  safe action—not every clickable element.
- Gold means attention or pending review, not failure.
- Clay means risk, blockage, destructive action, or urgent recovery.
- Local-only and offline states need explicit labels and icons in addition to
  color.
- Customer-facing screens use less semantic color than manager recovery tools.

## Contrast target

Normal text and interactive controls target WCAG 2.2 AA. Small slate text belongs
only on paper or bone surfaces. Sand is reserved for large or bold text on forest
and evergreen backgrounds.
