# Layout, Spacing, and Shape

## Spacing scale

Use an 8-pixel base rhythm with 4-pixel adjustments for dense data:

`4 · 8 · 12 · 16 · 24 · 32 · 40 · 48 · 64 · 80`

- Mobile page gutter: 16–20px.
- Desktop application gutter: 28–32px.
- Marketing content maximum: 1328px.
- Dense table/board row: 44–64px, depending on secondary context.
- Touch target: at least 44 by 44 CSS pixels.

## Shape

- Controls: 10–12px radius.
- Standard surfaces: 14–18px radius.
- Marketing or hero surfaces: up to 24px radius.
- Pills: fully rounded, reserved for bounded status or compact filters.
- Shadows: low-opacity evergreen, wide and soft. Borders remain the primary
  surface separator inside operational tools.

## Responsive composition

- Field mobile prioritizes current work over dashboard summaries.
- Manager mobile exposes one category and one active tool at a time.
- Manager desktop can combine navigation, board or collection, and contextual
  inspector.
- Customer mobile defaults to compact property selection and recent proof.
- Marketing uses large editorial spacing; authenticated tools use measured density.
