# Component Catalog

This catalog defines the minimum reusable visual language required before
high-fidelity concepts become product code.

## Navigation

- Public header and compact mobile menu
- Persona switcher
- Desktop application rail
- Mobile bottom navigation
- Manager category and tool picker
- Breadcrumb or context-return bar

## Actions and forms

- Primary, secondary, quiet, and destructive buttons
- Icon button and split action
- Text, select, date/time, search, and textarea fields
- Filter chip, status pill, and segmented control
- Dialog, mobile sheet, confirmation, and inline save state

## Operational data

- Metric tile with trend or exception context
- Route stop and assigned-job record
- Schedule block and crew lane
- Data table with selection and bounded pagination
- Timeline and immutable audit record
- Before/after evidence pair
- Readiness checklist and blocker summary

## Feedback and recovery

- Loading skeleton and slow-start message
- Valid empty state
- Offline or local-only state
- Persistence unavailable state
- Conflict requiring review
- Field validation and form-level error summary
- Success confirmation with next action
- Destructive confirmation and recovery outcome

Every component requires keyboard, focus, text-zoom, reduced-motion, and mobile
touch behavior before implementation approval.
